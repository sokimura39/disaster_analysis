# 災害救助法適用件数

平成26年度から令和7年度までの災害救助法適用件数を[地図上に表示](https://sokimura39.github.io/disaster_analysis/map.html)。

## 出典

[内閣府防災情報HP](https://www.bousai.go.jp/oyakudachi/info_saigaikyujo.html)での公表資料をもとに作成。整理状況によって、以下の資料を下に作成している。

- 平成26年度から令和6年度までについては、内閣府にてとりまとめられている[災害救助法の適用実績](https://www.bousai.go.jp/oyakudachi/pdf/kyuujo_c15.pdf)をデータ化。
- 令和7年度については、上記資料にとりまとまっていないため、[災害救助法の適用状況](https://www.bousai.go.jp/taisaku/kyuujo/kyuujo_tekiyou.html)の各災害のプレスをもとに作成。

データ整形・コーディングにおいて生成AIを使用。
